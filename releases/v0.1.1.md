# v0.1.1

## Breaking MCP tool schema changes

None.

## Changes

- Support explicit `0.0.0.0` listening for HTTP and SSE through the existing `--listen` flag, `MCP_LISTEN` environment variable, or `listen` configuration field.
- Preserve the default `127.0.0.1` listener and rejection of other specific non-loopback addresses.
- Update CLI help and English/Chinese documentation with wildcard usage, reachable client addresses, and a Docker example using a locally built image.

## 更新

- HTTP 和 SSE 支持通过现有 `--listen` 参数、`MCP_LISTEN` 环境变量或 `listen` 配置字段显式监听 `0.0.0.0`。
- 默认仍监听 `127.0.0.1`，其他具体非本机地址仍被拒绝。
- 更新命令帮助和中英文文档，说明通配监听、客户端连接地址及本地构建镜像的 Docker 用法。

## HTTP security / HTTP 安全说明

HTTP and SSE still have no authentication or TLS. Clients should connect using the server's reachable IP or hostname, rather than `0.0.0.0`.

HTTP 和 SSE 仍无身份认证和 TLS。客户端应使用服务器可访问的 IP 或主机名连接，不要使用 `0.0.0.0`。
